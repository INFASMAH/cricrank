# CricRank 🏏

Cricket Tournament Management Platform

## Features
- Live Scoring
- Team & Player Rankings
- Fan Vote
- Team Gallery
- Chat Support
- Announcements
- PWA (Install as App)

## Deploy
Push to `main` branch → Auto deploy to Vercel

## Update Workflow
1. Edit `index.html` (get from Claude)
2. `git add . && git commit -m "update" && git push`
3. GitHub Actions → auto deploy → users get update banner
